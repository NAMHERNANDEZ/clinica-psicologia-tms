# FASE 12.8 — Reportes Clínicos

**Goal**  
Sistema de generación de reportes clínicos en PDF, exportación de datos, dashboards y exportación programada.

## Backend

### Endpoints a implementar

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/reports/templates` | GET | Listar plantillas de reporte |
| `/api/reports/templates` | POST | Crear plantilla |
| `/api/reports/generate` | POST | Generar reporte (PDF/Excel/CSV) |
| `/api/reports/:id` | GET | Obtener reporte generado |
| `/api/reports/:id/download` | GET | Descargar archivo |
| `/api/reports/schedule` | POST | Programar reporte recurrente |
| `/api/reports/scheduled` | GET | Listar reportes programados |

### Modelo de datos

```sql
-- Plantillas de reporte
CREATE TABLE report_templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  name TEXT NOT NULL,
  description TEXT,
  type TEXT NOT NULL CHECK (type IN ('PATIENT_SUMMARY', 'TREATMENT_SUMMARY', 'FOLLOWUP_SUMMARY', 'SCALES_REPORT', 'CUSTOM')),
  template_json TEXT NOT NULL,      -- Definición de secciones, campos, formato
  output_format TEXT DEFAULT 'PDF' CHECK (output_format IN ('PDF', 'EXCEL', 'CSV', 'HTML')),
  is_active INTEGER DEFAULT 1,
  created_by INTEGER,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);

-- Reportes generados
CREATE TABLE generated_reports (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  template_id INTEGER NOT NULL,
  patient_id INTEGER,               -- NULL para reportes globales
  generated_by INTEGER NOT NULL,
  status TEXT DEFAULT 'PENDING' CHECK (status IN ('PENDING', 'GENERATING', 'COMPLETED', 'FAILED')),
  file_path TEXT,                   -- Ruta en R2
  file_size INTEGER,
  mime_type TEXT,
  generated_at TEXT,
  completed_at TEXT,
  error_message TEXT,
  FOREIGN KEY (template_id) REFERENCES report_templates(id)
);

-- Reportes programados
CREATE TABLE scheduled_reports (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  template_id INTEGER NOT NULL,
  name TEXT NOT NULL,
  cron_expression TEXT NOT NULL,    -- Expresión cron
  recipients_json TEXT,             -- Emails destinatarios
  filters_json TEXT,                -- Filtros (pacientes, fechas, etc.)
  is_active INTEGER DEFAULT 1,
  last_run_at TEXT,
  next_run_at TEXT,
  created_by INTEGER,
  created_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (template_id) REFERENCES report_templates(id)
);
```

## Frontend

### Admin/Reports Page

- Lista de plantillas con: nombre, tipo, formato, estado
- Botón "Crear plantilla" → editor visual (drag & drop secciones)
- Botón "Generar reporte" → modal con selector de plantilla, filtros, formato
- Lista de reportes generados con: nombre, estado, fecha, descargar
- Sección "Programados" con: nombre, cron, próximo envío, estado

### Editor de plantillas (visual)

- Drag & drop de secciones: Header, Patient Info, Treatment Summary, Scales, Followups, Notes, Footer
- Configuración de campos por sección
- Preview en tiempo real
