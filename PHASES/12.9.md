# FASE 12.9 — Portal Paciente

**Goal**  
Portal web para pacientes: acceso a citas, documentos, consentimientos, escalas, mensajes, seguimiento de tratamientos.

## Backend

### Autenticación y Autorización

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/patient/auth/login` | POST | Login paciente (email + password) |
| `/api/patient/auth/register` | POST | Registro (verificación email/SMS) |
| `/api/patient/auth/refresh` | POST | Refresh token |
| `/api/patient/auth/forgot-password` | POST | Solicitar reset password |
| `/api/patient/auth/reset-password` | POST | Reset password con token |

### Endpoints del Portal

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/patient/profile` | GET | Perfil del paciente |
| `/api/patient/appointments` | GET | Lista de citas (próximas, pasadas) |
| `/api/patient/appointments/:id` | GET | Detalle de cita |
| `/api/patient/appointments/:id/cancel` | POST | Cancelar cita |
| `/api/patient/documents` | GET | Lista documentos |
| `/api/patient/documents/:id/download` | GET | Descargar documento |
| `/api/patient/consents` | GET | Consentimientos firmados/pendientes |
| `/api/patient/consents/:id/sign` | POST | Firmar consentimiento |
| `/api/patient/scales` | GET | Escalas aplicadas + historial |
| `/api/patient/scales/:id/result` | GET | Resultado de escala |
| `/api/patient/treatments` | GET | Tratamientos activos/historial |
| `/api/patient/followups` | GET | Seguimientos programados |
| `/api/patient/messages` | GET | Mensajes/notificaciones |
| `/api/patient/messages/:id/read` | POST | Marcar como leído |
| `/api/patient/notifications` | GET | Notificaciones (recordatorios, alertas) |

### Modelo de datos (extensiones)

```sql
-- Pacientes con credenciales portal
ALTER TABLE patients ADD COLUMN portal_email TEXT UNIQUE;
ALTER TABLE patients ADD COLUMN portal_password_hash TEXT;
ALTER TABLE patients ADD COLUMN portal_active INTEGER DEFAULT 1;
ALTER TABLE patients ADD COLUMN portal_last_login TEXT;
ALTER TABLE patients ADD COLUMN portal_password_reset_token TEXT;
ALTER TABLE patients ADD COLUMN portal_password_reset_expires TEXT;

-- Tokens de sesión portal
CREATE TABLE patient_sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  patient_id INTEGER NOT NULL,
  token_hash TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (patient_id) REFERENCES patients(id)
);

-- Notificaciones push/email
CREATE TABLE patient_notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  patient_id INTEGER NOT NULL,
  type TEXT NOT NULL,  -- APPOINTMENT_REMINDER, DOCUMENT_READY, SCALE_DUE, MESSAGE, ALERT
  title TEXT NOT NULL,
  body TEXT,
  reference_type TEXT,    -- appointment, document, scale, message
  reference_id INTEGER,
  read_at TEXT,
  sent_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (patient_id) REFERENCES patients(id)
);
```

#### Características clave

- **Responsive** (mobile-first)
- **Notificaciones push** (Web Push API)
- **Modo offline** (Service Worker para cache)
- **Accesibilidad** (WCAG 2.1 AA)
- **Internacionalización** (ES/EN)
