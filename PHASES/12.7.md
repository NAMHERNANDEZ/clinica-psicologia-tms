# FASE 12.7 — Escalas Psicológicas

**Goal**  
Implementar sistema de escalas psicológicas validadas: PHQ-9, GAD-7, BDI-II, PCL-5, AUDIT, DASS-21, etc.

## Backend

### Endpoints a implementar

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/assessments/scales` | GET | Listar escalas disponibles |
| `/api/assessments/scales/:id` | GET | Obtener detalles de una escala |
| `/api/assessments/patient/:patientId/scale/:scaleId` | POST | Aplicar escala a paciente |
| `/api/assessments/patient/:patientId/scale/:scaleId` | GET | Obtener historial de aplicaciones |
| `/api/assessments/patient/:patientId/scale/:scaleId/last` | GET | Última aplicación |

### Modelo de datos

```sql
-- Escalas disponibles
CREATE TABLE assessment_scales (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  code TEXT NOT NULL UNIQUE,        -- PHQ9, GAD7, BDI2, PCL5, AUDIT, DASS21
  name TEXT NOT NULL,               -- PHQ-9, GAD-7, BDI-II, PCL-5, AUDIT, DASS-21
  description TEXT,
  version TEXT DEFAULT '1.0',
  questions_json TEXT NOT NULL,     -- JSON con preguntas, opciones, scoring
  scoring_rules_json TEXT NOT NULL, -- Reglas de scoring, cutoff points
  is_active INTEGER DEFAULT 1,
  created_at TEXT DEFAULT (datetime('now'))
);

-- Aplicaciones de escalas
CREATE TABLE assessment_results (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  patient_id INTEGER NOT NULL,
  scale_id INTEGER NOT NULL,
  scale_version TEXT,
  responses_json TEXT NOT NULL,     -- Respuestas del paciente
  score INTEGER NOT NULL,           -- Puntuación total
  interpretation TEXT,              -- Interpretación según cutoff
  severity_level TEXT,              -- LEVE, MODERADO, SEVERO, etc.
  administered_by INTEGER,          -- Quién aplicó
  administered_at TEXT DEFAULT (datetime('now')),
  notes TEXT,
  FOREIGN KEY (patient_id) REFERENCES patients(id),
  FOREIGN KEY (scale_id) REFERENCES assessment_scales(id)
);

CREATE INDEX idx_assessment_patient ON assessment_results(patient_id);
CREATE INDEX idx_assessment_scale ON assessment_results(scale_id);
CREATE INDEX idx_assessment_date ON assessment_results(administered_at);
```

## Frontend

### PatientChartPage - Pestaña "Escalas"

- Lista de escalas aplicadas con: nombre, fecha, score, interpretación
- Botón "Aplicar escala" → modal con selector de escala
- Visualización de historial gráfico (score vs tiempo)
- Interpretación automática con colores (verde/amarillo/rojo)

### Modal "Aplicar Escala"

- Selector de escala (PHQ-9, GAD-7, etc.)
- Formulario dinámico según preguntas de la escala
- Cálculo automático de score al enviar
- Interpretación automática con cutoff points
