# FASE 12.6 — Seguimiento Clínico

**Goal**  
Implementar sistema de seguimiento clínico para pacientes: programar, gestionar y dar seguimiento a citas de control, revisiones y tratamientos continuos.

## Backend

### Endpoints a implementar

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/followups` | POST | Crear nuevo seguimiento |
| `/api/followups` | GET | Listar seguimientos (filtros: patient_id, status, date_range) |
| `/api/followups/:id` | GET | Obtener detalle de un seguimiento |
| `/api/followups/:id` | PUT | Actualizar seguimiento |
| `/api/followups/:id/complete` | POST | Marcar como completado con outcome |
| `/api/followups/:id` | DELETE | Soft delete (soft delete) |

### Modelo de datos

```sql
CREATE TABLE followups (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  clinic_id INTEGER NOT NULL DEFAULT 1,
  patient_id INTEGER NOT NULL,
  type TEXT NOT NULL CHECK (type IN ('CONTROL', 'REVISION', 'TRATAMIENTO', 'URGENCIA', 'TELEMEDICINA')),
  scheduled_at TEXT NOT NULL,
  completed_at TEXT,
  status TEXT DEFAULT 'PENDIENTE' CHECK (status IN ('PENDIENTE', 'EN_PROGRESO', 'COMPLETADO', 'CANCELADO', 'NO_ASISTIO')),
  priority TEXT DEFAULT 'NORMAL' CHECK (priority IN ('BAJA', 'NORMAL', 'ALTA', 'URGENTE')),
  notes TEXT,
  outcome TEXT,
  outcome_notes TEXT,
  created_by INTEGER,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (patient_id) REFERENCES patients(id)
);

CREATE INDEX idx_followups_patient ON followups(patient_id);
CREATE INDEX idx_followups_status ON followups(status);
CREATE INDEX idx_followups_scheduled ON followups(scheduled_at);
```

### Tipos de seguimiento

- **CONTROL**: Control rutinario post-tratamiento
- **REVISION**: Revisión de resultados o evolución
- **TRATAMIENTO**: Sesión de tratamiento continuado
- **URGENCIA**: Seguimiento de urgencia
- **TELEMEDICINA**: Seguimiento por telemedicina

### Estados

- **PENDIENTE**: Programado, pendiente de realizarse
- **EN_PROGRESO**: En curso
- **COMPLETADO**: Finalizado con outcome
- **CANCELADO**: Cancelado
- **NO_ASISTIO**: Paciente no asistió
