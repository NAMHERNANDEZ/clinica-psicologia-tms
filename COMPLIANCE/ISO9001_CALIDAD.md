# Sistema de Gestion de Calidad - ISO 9001
## Clinica de Psicologia y Terapia Magnetica Transcraneal

### 1. Politica de Calidad
Brindar servicios de psicologia y terapia magnetica transcraneal con estandares de calidad que superen las expectativas de nuestros pacientes, garantizando seguridad clinica y mejora continua.

### 2. Indicadores de Calidad (Quality Metrics)

| Indicador | Meta | Unidad | Frecuencia |
|-----------|------|--------|------------|
| Tasa de completitud de tratamiento | >= 85% | % | Trimestral |
| Satisfaccion del paciente | >= 90/100 | score | Mensual |
| Tasa de efectos adversos | <= 5% | % | Mensual |
| Asistencia a sesiones | >= 90% | % | Mensual |
| Adherencia a protocolo | >= 95% | % | Mensual |
| Mejoria clinica | >= 70% | % | Trimestral |
| Tasa de no-show | <= 10% | % | Mensual |
| Tiempo promedio de espera | <= 15 min | hours | Semanal |
| Tiempo de respuesta a consulta | <= 24h | hours | Semanal |

### 3. Procesos Clave

#### 3.1 Atencion al Paciente
1. Recepcion y registro
2. Evaluacion inicial (escalas validadas: BDI-II, GAD-7, PHQ-9)
3. Diseno de plan de tratamiento
4. Ejecucion de sesiones (SOAP notes)
5. Seguimiento y reevaluacion
6. Alta clinica

#### 3.2 Terapia Magnetica Transcraneal
1. Medicion de umbral motor
2. Seleccion de protocolo (basado en evidencia)
3. Asignacion de perfil al paciente
4. Administracion de sesiones
5. Registro de respuesta clinica
6. Monitoreo de efectos adversos
7. Ajuste de parametros segun respuesta

#### 3.3 Control Documental
- Expediente clinico digital (ISO/NOM compliant)
- Notas SOAP estructuradas
- Consentimientos informados con hash digital
- Registro de auditoria completo

### 4. Medicion y Analisis
- Dashboard de metricas en tiempo real
- Reportes trimestrales de calidad
- Analisis de tendencias por indicador
- Comparativa contra metas establecidas

### 5. Mejora Continua
- Revision mensual de indicadores
- Acciones correctivas documentadas
- Retroalimentacion de pacientes
- Actualizacion de protocolos segun evidencia

### 6. Responsabilidades
- **Administrador**: Supervisar cumplimiento de indicadores
- **Terapeuta**: Registrar datos clinicos completos
- **Recepcion**: Gestionar citas y seguimiento de asistencia
- **Calidad**: Analizar metricas y proponer mejoras
